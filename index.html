    Resumen de la evaluación

    ROM = rango recorrido (máx − mín). Signos: + = izquierda / flexión / valgo / hombro izq adelante. Asimetría = diferencia de ROM entre lados.

    En vivo

    (est.) = estimado desde una sola cámara frontal: usalo para comparar entre lados o entre evaluaciones, no como valor absoluto. "Calibrar" toma 2 s con la persona quieta: pone el neutro, mide el margen de error de cada métrica y descarta cuadros donde un segmento se deforma.
